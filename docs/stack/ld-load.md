# 权重加载

目标是让权重尽快从磁盘到达正确的那张卡。safetensors 支持 mmap，配合 TP 时每个 rank 只读自己那一片，不需要先把整个模型读进 CPU 内存再切。冷启动时间常被忽视，但它直接决定了扩缩容能有多快。

- **按 rank 切片读**：TP 下 column-parallel 按输出维切，row-parallel 按输入维切。
- **流式**：边读边拷到 GPU，避免 CPU 内存峰值翻倍。
- **加速冷启动**：预先按 TP 布局切好的 checkpoint、从对象存储并行拉取，或者直接从另一个实例的显存拷贝权重。
- **RL 场景**：训练端更新权重后要热更新推理引擎，这条路径就是权重同步。
